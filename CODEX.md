# Codex project entry point

This is the Java/Spring Boot continuous-agent harness, with a local Ollama coding run against a task-tracker CLI as its first target. [AGENTS.md](AGENTS.md) is the canonical repository instruction file: it maps the code, gives test commands, and records Git, trust-boundary, and cleanup rules.

For a resumed task, read [docs/STATUS.md](docs/STATUS.md) and the relevant part of the [implementation plan](docs/plans/2026-09-20-local-task-tracker-implementation.md). Tasks 1–4 are merged; Task 5 is next as of the handoff date. Use [docs/development.md](docs/development.md) for local setup and shutdown. Verify GitHub and the checkout before relying on any recorded status.
